# 一键部署验收

日期：2026-09-10。入口为项目根目录 `一键部署.cmd`，它调用 Windows PowerShell 5 兼容的 `一键部署.ps1`；部署检查由 `scripts/deployment.py` 完成。

## 支持范围

Windows x64 联网部署到可写目录。默认独立虚拟环境，不复用作者 Conda 已安装的库。已有 Python/Ollama 可复用软件本身；依赖安装到项目 `.runtime/venv-目录标识/`。同事无需编辑脚本中的路径。

配置与问答记录保留；`.runtime/current.json` 记录当前目录与解释器，启动入口优先使用它。迁移后重新部署，根据新目录标识创建新环境，不删除旧环境。

## 已执行检查

- Windows PowerShell 5 的检查模式在中文、空格、括号目录运行通过，不创建 .runtime/logs，也不安装程序。
- 缺少论文时，在下载和安装之前返回失败。
- pytest 共 20 项通过，包含版本缺失/不匹配检测、环境记录归属、迁移目录检查模式及原产品回归。
- 实际创建 `include-system-site-packages=false` 的新 Python 3.12.3 虚拟环境，从依赖安装流程开始验证，不借用作者 qwen 环境的 Python 包。

## 限制

这台机器原本有 Python、Ollama 与两个模型缓存，因此新 Windows 上 WinGet 首次安装 Python/Ollama、首次下载 9B/BGE 权重的分支没有实机验证。安装命令依据官方 WinGet 包清单与文档；公司安装权限、网络代理及剩余磁盘空间仍会影响结果。

本脚本不包含模型权重，交付包不能当作离线安装包。默认 9B 模型的答案质量仍适用产品验收报告中的边界，部署成功不等于未知问题全部正确。
