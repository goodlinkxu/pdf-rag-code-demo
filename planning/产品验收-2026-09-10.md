## 本轮修复

- 原 chat 在用户退出后才统一回答；现在每输入一题立即回答、保存。
- 新增浏览器页面与 Windows 启动入口。首次启动会查找项目虚拟环境、当前 Python 和已登记的 Conda 环境，不依赖作者硬编码路径。
- 提问、三题录入、查看原文、登记核对、下载提交文件均可在页面完成。
- 答案先显示，技术过程折叠；状态和操作使用中文；历史记录限高滚动；保留浏览器草稿。
- 后台任务有阶段提示，重复点击被拦截。网页记录可重试运行或引用失败的题目，成功结果与核对状态保留。
- doctor 在环境故障时返回非零；ask/batch 有失败时返回非零。显式指定不存在的配置不再悄悄回退。
- 设备默认 auto。默认模型改为本机已有的 qwen3.5:9b，输出预算 3000；1.7B 留在轻量配置中。
- 使用 JSON Schema 约束生成；限制过长的声明、引用和列表。模型明示 missing_information 却标 answered 时，仅保守降为 partial/insufficient，不补写或删除事实。
- 引用修复不得修改答案状态、事实或缺失信息；不得靠删掉答案变成拒答绕过校验。
- 对比回答失败不覆盖有效 RAG 答案；失败原始响应保留在 trace。
- 页面只监听本机，限制可下载文件、请求体和并发操作，写操作验证页面令牌与 Host。

Schema 接口依据：[Ollama 官方 structured outputs 文档](https://docs.ollama.com/capabilities/structured-outputs)。Schema 约束的是输出结构，不能保证事实正确。
