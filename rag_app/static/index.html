配置说明

1. 按项目 tutor.md 安装 Python 依赖。

2. 启动 Ollama，安装配置中的模型。

3. 点击“准备检索资料”，完成后提问。

问题与论文发送至配置中的 Ollama 服务，默认在本机运行。首次使用会下载检索模型。
